## 一、系统概述

OMS（Order Management System）系统已支持与主流电商及营销平台的对接，实现多平台数据统一管理。

### 平台集成

| 平台 | 技能 | 功能覆盖 |
|------|------|----------|
| 京东开放平台 | `oms-jd-integration` | 订单同步、库存管理、物流追踪、退货处理 |
| 小红书开放平台 | `oms-xhs-integration` | 笔记数据、KOL合作、薯店订单、UTM归因 |

### 接入方式

- 京东：OAuth 2.0 + MD5签名认证
- 小红书：OAuth 2.0 + MD5签名认证

## 二、核心业务场景

### 场景1：新客户首单转化

**用户痛点**：新客户下单后，不知道其消费偏好，无法精准推荐，导致复购率低。

**解决思路**：
```
客户下单 → 自动识别身份 → 查询历史画像 → 匹配促销 → 路由最优仓库
```

### 场景2：限时大促防超卖

**用户痛点**：大促期间库存不同步，多平台超卖引发客诉。

**解决思路**：
```
实时库存查询 → 预扣库存 → 订单成交 → 释放未支付库存
```

### 场景3：跨渠道退货（Anywhere Return）

**用户痛点**：客户在A平台买的商品，只能在A平台退货，不方便导致差评。

**解决思路**：
```
退货申请 → 资格校验 → 就近门店退/上门取 → 质检分类 → 库存再流转
```

### 场景4：会员积分与促销联动

**用户痛点**：促销和积分各自为政，无法根据会员等级差异化营销。

**解决思路**：
```
识别会员等级 → 积分抵扣 → 优惠券叠加 → 阶梯优惠
```

### 场景5：O2O分润结算

**用户痛点**：线上订单线下门店履约，佣金分润规则复杂，容易出错。

**解决思路**：
```
订单成交 → 识别履约方 → 计算分润比例 → 生成结算单 → 财务凭证
```

### 场景6：每日对账

**用户痛点**：多平台订单数据与系统不一致，财务对账耗时。

**解决思路**：
```
拉取平台账单 → 与系统订单比对 → 差异标红 → 生成凭证 → 导出报表
```

## 三、预置业务流程

### 流程A：订单履约全流程

```
订单捕获 → 用户识别 → 库存检查 → 促销计算 → 订单路由 → 佣金计算
```

**解决的问题**：
- 多平台订单格式混乱 → 统一标准化
- 不知道客户是谁 → 身份识别
- 热门商品超卖 → 库存预扣
- 优惠叠加混乱 → 规则引擎
- 发货路径不优 → 智能路由
- 分润核算困难 → 自动计算

### 流程B：退货处理全流程

```
资格校验 → 退款处理 → 物流追踪 → 质量检验 → 缺陷分类 → 库存再上架
```

### 流程C：对账全流程

```
账单核对 → 凭证生成 → 报表导出
```

## 五、自定义场景配置

### 如何设计新流程

**Step 1：明确业务目标**
- 要解决什么问题？
- 涉及哪些角色（客户/客服/财务/仓库）？
- 关键节点有哪些？

**Step 2：选择技能组件**

| 目标 | 推荐技能 |
|------|----------|
| 识别用户 | oms-one-id-merge |
| 检查库存 | oms-inventory-realtime |
| 计算优惠 | oms-promotion-engine |
| 分配订单 | oms-order-routing |
| 处理退货 | oms-returns-crosschannel |
| 物流追踪 | oms-returns-logistics |
| 分润结算 | oms-profit-sharing |
| 财务核对 | oms-reconciliation |

**Step 3：配置数据流转**
```
输入数据 → 步骤1(技能A) → 输出数据 → 步骤2(技能B) → ...
```

**Step 4：设定业务规则**
- 超卖阈值是多少？
- 优惠叠加优先级？
- 分润比例？

## 六、典型行业方案

### 服装行业

**痛点**：SKU多、库存分散、促销复杂

**推荐流程**：
```
订单捕获 → 颜色尺码校验 → 库存查询(多仓) → 促销计算(多券叠加) → 路由(最近门店) → 佣金计算
```

### 3C数码

**痛点**：高价商品防黄牛、售后保外维修

**推荐流程**：
```
订单捕获 → 黄牛检测 → 实名认证 → 库存检查 → 促销计算 → 路由 → 延保推荐 → 佣金计算
```

### 生鲜食品

**痛点**：保鲜期短、损耗高、时效要求高

**推荐流程**：
```
订单捕获 → 库存查询(效期管理) → 冷藏包装校验 → 路由(最近冷链仓) → 优先发货 → 佣金计算
```

### 美妆护肤

**痛点**：套装组合、赠品管理、过敏售后

**推荐流程**：
```
订单捕获 → 套装拆解 → 库存查询 → 赠品校验 → 促销计算(买赠) → 路由 → 售后(过敏保障) → 佣金
```

## 八、常见问题

**Q1：现有系统如何对接？**
> 通过API调用技能服务，输入JSON格式数据，获取结构化输出

**Q2：业务规则如何配置？**
> 每个技能的输入参数支持自定义，如佣金比例、优惠门槛等

**Q3：可以只启用部分流程吗？**
> 可以，按需选择单个技能或组合使用

**Q4：促销规则经常变怎么办？**
> 促销引擎支持参数化配置，运营可随时调整
